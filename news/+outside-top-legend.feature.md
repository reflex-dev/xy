Added `xy.legend(loc="outside top")`, a legend band above the plot that never covers data: the plot shrinks to make room, and entries use as many columns as fit the width before wrapping into rows. `loc="best"` now moves the legend into that band on its own when every position inside the plot would cover marks — stacked areas, many series, and bars that reach the axis maximum — and stays inside whenever a corner is empty. Matplotlib's `"outside upper center"` spelling is accepted too, the browser and the SVG/PNG/PDF exports wrap the same entries into the same rows, and `xy.pyplot`'s `legend(loc="best")` keeps Matplotlib's in-plot behavior.
