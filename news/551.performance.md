Static PNG export no longer pays per-pixel work for things that cannot change per pixel. Upscaled heatmaps and `pcolormesh` color each grid cell once per destination row run instead of re-normalizing and colormapping every output pixel, the plot background fills its fully covered interior as a row copy when its edges sit on subpixel coordinates, and fully transparent strokes and fills (such as gridlines styled off) are skipped. Output is byte-identical. On the release audit's 80×120 `pcolormesh` row the native rasterize-and-encode stage dropped from about 19 ms to about 3.3 ms, and every `xy.pyplot` family's 1800×840 PNG export got roughly 5 ms faster.
