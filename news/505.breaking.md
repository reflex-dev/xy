The Reflex integration's chart data plane no longer uses socket.io. `/_xy` is
now a Reflex channel on the app's own event websocket, which means `xy[reflex]`
requires a Reflex that ships the channel transport and an app on the default
`transport="websocket"`; `transport="socketio"` and `transport="polling"` apps
can no longer serve charts. `reflex_xy.XYNamespace` and `reflex_xy.XY_NAMESPACE`
are replaced by `reflex_xy.XYChannel` and `reflex_xy.XY_PLANE`, and
`reflex_xy.namespace` by `reflex_xy.data_plane`. Application code that only
uses `XYPlugin`/`setup()` and the chart components is unaffected.
